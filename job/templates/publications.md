# Publications

Your publications, presentations, patents and thesis, each written exactly as
you cite it. Resumes and CVs print these lines word for word, by ID, and a
check compares every printed citation with this file. The /job skill sets it
up with you once and adds to it only after you confirm. It copies the file to
backups\ before every change.

One citation per line (publications.md is read only from lines that start
with "- P-"):

    - P-001 | <type> | <citation exactly as you write it> | ascii: <plain-letter version> | doi:<doi>

- type: journal, preprint, conference, patent or thesis.
- Put *asterisks* around text that prints in italics, such as a species
  name or a journal title.
- ascii: (optional) only for a citation with characters the PDF font cannot
  show, such as Greek letters: the same citation with those characters
  spelled out (beta-lactamase). Setup lists the citations that need one, and
  you approve each rendering once.
- doi: (optional).
