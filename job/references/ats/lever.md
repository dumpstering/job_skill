# Lever

Links on `jobs.lever.co` or `jobs.eu.lever.co`.

- Lever's posting data has no form questions; read them on the application
  page (the posting's `/apply` link).
- Attaching the resume fills fields from it, so attach it first, then check
  every filled field against the tailored resume.
- A "Success!" message after the resume uploads means the file uploaded. It
  is not the application being sent.
- Lever forms can show an hCaptcha. That is the user's part.
